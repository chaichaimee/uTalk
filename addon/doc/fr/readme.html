uTalk


Écoutez chaque action de Copier, Coller, Couper, Annuler et Enregistrer en temps réel — dans les mots de votre choix.


auteur : chai chaimee

url : https://github.com/chaichaimee/uTalk


Introduction


uTalk énonce une courte confirmation chaque fois que vous utilisez un raccourci d'édition courant — Copier, Coller, Couper, Annuler, Rétablir, Tout sélectionner, Enregistrer, Copier le chemin et Copier le fichier. Au lieu de vous demander si votre Ctrl+C a réellement fonctionné, uTalk annonce discrètement "copier" (ou tout autre mot de votre choix) juste après l'action.


Chaque mot annoncé peut être remplacé par votre propre texte, et vous pouvez même conserver deux ensembles complets d'annonces — par exemple l'anglais et votre langue maternelle — et basculer instantanément entre eux d'un simple appui sur une touche.


uTalk accorde également une attention particulière à la copie de texte sélectionné lors de la navigation sur le Web en Mode navigation de NVDA, où un Ctrl+C normal échoue souvent silencieusement car la sélection n'existe que dans le tampon virtuel de NVDA.

uTalk écoute directement ces raccourcis Windows standard. Votre raccourci continue toujours de fonctionner normalement — uTalk ajoute simplement une confirmation vocale par-dessus.

Fonctionnalités

1. Confirmation vocale pour les commandes quotidiennes


Chaque fois que vous appuyez sur Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+Z, Ctrl+Y (ou Ctrl+Maj+Z), Ctrl+A ou Ctrl+S, uTalk laisse passer la frappe vers l'application en premier, puis énonce un mot bref confirmant ce qui s'est passé. Par défaut, les mots sont en anglais simple : "copy", "paste", "cut", "undo", "redo", "select all" et "save".


Pour que NVDA reste réactif, les annonces ne sont jamais prononcées instantanément lors de la frappe — uTalk attend une fraction de seconde (100 millisecondes) avant de parler, afin que l'application ait le temps de terminer l'action.


Par mesure de sécurité, tout texte annoncé est limité à 200 caractères ; si vous configurez une phrase personnalisée très longue, elle sera raccourcie avec "...tronqué" à la fin.

2. Gestion intelligente de la copie en Mode navigation


La copie de texte lors de la lecture d'une page Web en Mode navigation de NVDA fonctionne différemment de la copie dans un champ éditable normal, et uTalk gère correctement les deux cas :


Étape par étape, lorsque vous appuyez sur Contrôle+C :


1. uTalk vérifie si votre focus actuel se trouve dans un document virtuel du Mode navigation (par exemple, une page Web).


2. Si vous êtes en Mode navigation : une sélection de texte effectuée avec Maj+Touches fléchées n'existe que dans le tampon virtuel de NVDA. uTalk lit le texte sélectionné directement depuis le tampon virtuel et le place dans le presse-papiers à l'aide de la fonction de NVDA.


3. Si vous n'êtes pas en Mode navigation (par exemple, lors de la saisie dans un champ de texte) : une sélection réelle au niveau du système d'exploitation existe déjà, uTalk transmet donc votre Ctrl+C à l'application.


4. Dans les deux cas, une fois la copie effectuée, uTalk annonce "copier" (ou votre mot personnalisé).

3. Annonces spécifiques à l'Explorateur pour Copier le chemin et Copier le fichier


L'Explorateur Windows possède deux raccourcis supplémentaires : Copier en tant que chemin (Ctrl+Maj+C) et Copier le fichier (Ctrl+Alt+C). uTalk vérifie si la fenêtre active appartient à l'Explorateur Windows avant d'annoncer ces commandes.

4. Un raccourci, deux fonctions : Basculement de langue et accès aux paramètres


NVDA+Alt+T est un raccourci unique qui se comporte différemment selon le nombre de pressions successives :


Appui simple — uTalk attend jusqu'u à 500 millisecondes pour voir si vous effectuez un autre appui. Si ce n'est pas le cas, il change votre langue d'annonce active et énonce immédiatement le nom de la nouvelle langue.


Double appui (ou plus) — Si un deuxième appui arrive dans les 600 millisecondes, uTalk ouvre la boîte de dialogue des Paramètres de NVDA directement sur la catégorie uTalk.


En interne, chaque appui réinitialise un court temporisateur pour distinguer un appui simple d'un double appui.

5. Phrases de commande entièrement personnalisables


L'ouverture du panneau des paramètres de uTalk vous offre un champ de texte pour le nom d'une langue alternative, ainsi qu'un champ pour chaque commande. Tout ce que vous tapez dans ces champs devient ce que NVDA prononce pour cette commande.


Un bouton "Restaurer les valeurs par défaut" réinitialise tous les champs.


L'enregistrement de vos modifications met à jour le module complémentaire en cours d'exécution immédiatement.


Pour éviter que la boîte de dialogue des paramètres ne se fige à l'ouverture, le panneau lit ses valeurs actuelles à partir des paramètres en mémoire du module.

6. Stockage fiable des paramètres


Vos phrases personnalisées sont enregistrées dans un fichier de configuration dans votre dossier de configuration utilisateur NVDA, dans un sous-dossier "ChaiChaimee" de manière sécurisée.


Si vous possédez une ancienne version de uTalk, le module déplace automatiquement vos paramètres existants lors du premier chargement.
