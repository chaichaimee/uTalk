uTalk


Entendez chaque confirmation de Copier, Coller, Annuler et Enregistrer, dans votre langue, uniquement lorsqu’elle s’est vraiment produite.


Auteur : chai chaimee

URL : https://github.com/chaichaimee/uTalk


Introduction


uTalk vous donne une confirmation vocale instantanée pour les commandes d’édition que vous utilisez tous les jours : Copier, Couper, Coller, Annuler, Rétablir, Sélectionner tout, Enregistrer, Copier en tant que chemin et Copier le fichier. Au lieu de vous demander si un raccourci a fonctionné, vous l’entendez.


uTalk vérifie que l’action a réellement pris effet avant de parler, afin de ne pas vous dire « copier » lorsque rien n’a été copié. Il fonctionne avec deux profils de langue entre lesquels vous pouvez basculer d’une seule pression, permet de définir un comportement différent pour chaque application et vous laisse choisir si les confirmations arrivent sous forme de synthèse vocale, de braille ou d’un bref bip. Chaque formule peut être modifiée selon vos propres termes.


Raccourcis clavier

NVDA+Alt+T
Appui simple : Basculer entre la langue principale et la langue alternative
Double appui : Ouvrir les paramètres d’uTalk
Triple appui : Activer ou désactiver uTalk pour l’application active
Quadruple appui : Couper ou rétablir les annonces d’uTalk
La commande de coupure du son et la commande pour l’application active peuvent également se voir attribuer leurs propres touches. Ouvrez le menu NVDA > Préférences > Gestes de commandes, recherchez la catégorie uTalk et attribuez une touche à « Mute or unmute uTalk announcements » ou « Turn uTalk off or on for the current application ». La commande à appuis multiples y apparaît sous le nom « uTalk multi tap ».

Touches annoncées par uTalk

Contrôle+C : Copier
Contrôle+X : Couper
Contrôle+V : Coller
Contrôle+Z : Annuler
Contrôle+Y ou Contrôle+Maj+Z : Rétablir
Contrôle+A : Sélectionner tout
Contrôle+S : Enregistrer
Contrôle+Maj+C : Copier en tant que chemin (annoncé uniquement dans l’Explorateur de fichiers)
Contrôle+Alt+C : Copier le fichier (annoncé uniquement dans l’Explorateur de fichiers)

uTalk transmet chacune de ces touches à l’application comme d’habitude. Il ajoute uniquement l’annonce.


Fonctionnalités


Confirmation intelligente de Copier et Couper

Après avoir appuyé sur Contrôle+C ou Contrôle+X, uTalk attend pour vérifier si le presse-papiers a réellement changé. Si c’est le cas, vous entendez « copier » ou « couper ». Si rien n’a été placé dans le presse-papiers, vous entendez à la place « Rien à copier » ou « Rien à couper ».


Exemple : Vous appuyez sur Contrôle+C sans rien avoir sélectionné. uTalk dit « Rien à copier » au lieu de confirmer une copie qui n’a jamais eu lieu.


Coller n’est annoncé que là où le collage est possible. En mode navigation et dans les champs en lecture seule, Contrôle+V n’est pas annoncé.


Vous pouvez désactiver cette vérification avec l’option « Announce copy, cut and paste only when they take effect » dans les paramètres. Lorsqu’elle est désactivée, le nom de la commande est toujours annoncé.


Copier en mode navigation

Sur les pages web et d’autres documents en mode navigation, une sélection n’existe qu’à l’intérieur de NVDA, de sorte que l’application ne copierait rien. uTalk copie votre texte sélectionné à votre place, afin que Contrôle+C fonctionne en mode navigation et soit confirmé comme n’importe quelle autre copie.


Une annonce par action

Si vous maintenez un raccourci enfoncé ou si vous appuyez dessus rapidement et à plusieurs reprises, uTalk vous donne une seule annonce au lieu d’une longue file de messages répétés.


Profils à deux langues

uTalk conserve deux ensembles de formules : la langue principale (anglais) et une langue alternative de votre choix. Appuyez une fois sur NVDA+Alt+T pour basculer entre les deux. uTalk annonce le nom de la langue vers laquelle vous avez basculé. NVDA mémorise la dernière langue utilisée.


Si une commande n’a pas de formule alternative, uTalk utilise sa formule anglaise. Si vous appuyez sur la touche de bascule avant d’avoir configuré une formule alternative, uTalk vous indique que la langue alternative n’est pas définie et vous rappelle d’ouvrir les paramètres.


Comment configurer la langue alternative :

1. Appuyez deux fois sur NVDA+Alt+T pour ouvrir les paramètres d’uTalk.
2. Dans « Alternate language code », saisissez le nom que vous souhaitez entendre lorsque vous passez à cette langue.
3. Dans les champs « Command translations », saisissez votre propre formule pour chaque commande : Copier, Copier le chemin, Copier le fichier, Couper, Coller, Rétablir, Enregistrer, Sélectionner tout et Annuler.
4. Activez OK pour enregistrer.
5. Appuyez une fois sur NVDA+Alt+T pour commencer à utiliser la langue alternative.

Choix de sortie

Choisissez comment uTalk vous fournit ses confirmations dans la liste « Announcement output » :


- Synthèse vocale et braille
- Synthèse vocale uniquement
- Braille uniquement
- Bip uniquement


Avec « Bip uniquement », chaque commande a sa propre tonalité, afin que vous puissiez distinguer Copier de Coller ou Enregistrer uniquement par la hauteur du son. Une tonalité d’erreur plus grave est jouée lorsqu’il n’y avait rien à copier ou à couper.


Niveau de détail des annonces

La liste « Announcement detail » comporte deux niveaux : Court et Détaillé.


Court indique uniquement le nom de la commande, par exemple « copier ».


Détaillé ajoute davantage d’informations :


- Copier, couper et coller signalent le nombre de caractères, ainsi que le nombre de lignes lorsqu’il y en a plus d’une. Par exemple : « copier 2 lignes 50 caractères ». Un saut de ligne tout à la fin du texte n’est pas compté comme une ligne supplémentaire.
- Dans les champs modifiables, annuler et rétablir vous indiquent ce qui a changé, par exemple « annuler a supprimé hello », « rétablir a ajouté world » ou « annuler a remplacé cat par dog ». Les longs extraits de texte sont raccourcis, et le texte composé uniquement d’espaces est décrit comme « whitespace ».


Les informations détaillées ne sont pas utilisées avec « Bip uniquement ». Pour les très longs textes et dans les applications qui lisent le texte trop lentement, annuler et rétablir indiquent uniquement le nom brut de la commande.


Règles par application

Vous pouvez décider comment uTalk se comporte dans chaque application. Chaque règle a la forme nom=valeur, une par ligne, où nom est le nom du programme (la terminaison « .exe » est facultative et la casse n’a pas d’importance) et valeur est l’un des éléments suivants :


- off : uTalk reste silencieux dans cette application
- main : utiliser toujours les formules de la langue principale dans cette application
- alt : utiliser toujours les formules de la langue alternative dans cette application


Par défaut, uTalk est silencieux dans l’Invite de commandes, PowerShell et Windows Terminal. Les applications sans règle suivent la langue que vous avez sélectionnée avec NVDA+Alt+T.


Comment ajouter une règle :

1. Appuyez deux fois sur NVDA+Alt+T pour ouvrir les paramètres d’uTalk.
2. Déplacez-vous vers le champ « Application rules ».
3. Saisissez une nouvelle ligne, par exemple : notepad=alt
4. Activez OK pour enregistrer.

Bascule rapide pour l’application active : Appuyez trois fois sur NVDA+Alt+T tout en travaillant dans une application. uTalk ajoute ou supprime une règle « off » pour celle-ci et vous l’indique, par exemple « uTalk off for notepad » ou « uTalk on for notepad ». La modification est enregistrée automatiquement.


Couper le son

Appuyez quatre fois sur NVDA+Alt+T pour couper toutes les annonces d’uTalk, et appuyez à nouveau quatre fois pour rétablir le son. Couper le son annule également toute annonce en attente d’être prononcée.


Formules personnalisables

Les formules de la langue principale sont Copier, Copier en tant que chemin, Copier le fichier, Couper, Coller, Rétablir, Enregistrer, Sélectionner tout et Annuler. Chacune dispose d’un champ alternatif dans les paramètres où vous pouvez écrire vos propres termes. Chaque formule peut contenir jusqu’à 200 caractères.


Paramètres sécurisés

La boîte de dialogue des paramètres vous protège contre les erreurs :


- Tout texte dépassant 200 caractères est refusé, et uTalk vous indique quel champ raccourcir.
- Une règle d’application non valide est refusée, et uTalk vous indique quelle ligne corriger. Utilisez nom=off, nom=main ou nom=alt.
- Le bouton « Restore Defaults » rétablit chaque paramètre à sa valeur d’origine.


Vos paramètres sont enregistrés dans le fichier uTalk.json situé dans userConfig\ChaiChaimee\uTalk\. Si vous avez utilisé une version antérieure d’uTalk, votre fichier de paramètres existant est déplacé automatiquement vers cet emplacement au démarrage de NVDA, et l’ancienne copie est supprimée une fois la nouvelle vérifiée. Si une valeur du fichier n’a pas le bon type, uTalk la remplace par la valeur par défaut.
