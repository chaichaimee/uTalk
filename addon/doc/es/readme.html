uTalk

Introducción


uTalk pronuncia una breve confirmación cada vez que utiliza un atajo de edición común — Copiar, Pegar, Cortar, Deshacer, Rehacer, Seleccionar todo, Guardar, Copiar ruta y Copiar archivo. En lugar de preguntarse si su Ctrl+C realmente funcionó, uTalk anuncia silenciosamente "copiar" (o cualquier palabra que prefiera) justo después de que ocurra la acción.


Cada palabra anunciada se puede reemplazar con su propio texto, e incluso puede mantener dos conjuntos completos de anuncios — por ejemplo, inglés y su idioma nativo — y cambiar entre ellos instantáneamente con una sola pulsación de teclas.


uTalk también presta especial atención a la copia de texto seleccionado mientras navega por la web en el Modo de exploración de NVDA, donde un Ctrl+C normal a menudo falla silenciosamente porque la selección solo existe dentro del búfer virtual de NVDA.


Atajos de teclado


NVDA+Alt+T
Una pulsación : Alternar entre inglés y su idioma alternativo para todos los anuncios
Doble pulsación : Abrir el panel de configuración de uTalk

Control+C
Una pulsación : Copiar, luego anunciar "copiar" (o su palabra personalizada)

Control+V
Una pulsación : Pegar, luego anunciar "pegar"

Control+X
Una pulsación : Cortar, luego anunciar "cortar"

Control+Z
Una pulsación : Deshacer, luego anunciar "deshacer"

Control+Y o Control+Mayús+Z
Una pulsación : Rehacer, luego anunciar "rehacer"

Control+A
Una pulsación : Seleccionar todo, luego anunciar "seleccionar todo"

Control+S
Una pulsación : Guardar, luego anunciar "guardar"

Control+Mayús+C
Una pulsación : Anunciar "copiar como ruta" (solo en el Explorador de Windows), luego realizar el atajo

Control+Alt+C
Una pulsación : Anunciar "copiar archivo" (solo en el Explorador de Windows), luego realizar el atajo

uTalk escucha directamente estos atajos estándar de Windows. Su atajo siempre sigue funcionando con normalidad — uTalk solo agrega una confirmación hablada encima de él.

Características

1. Confirmación hablada para comandos cotidianos


Siempre que presione Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+Z, Ctrl+Y (o Ctrl+Mayús+Z), Ctrl+A o Ctrl+S, uTalk permite que la pulsación de teclas pase primero a la aplicación y luego, poco después, pronuncia una palabra breve confirmando lo que sucedió. De forma predeterminada, las palabras son en inglés plano: "copy", "paste", "cut", "undo", "redo", "select all" y "save".


Para mantener la capacidad de respuesta de NVDA, los anuncios nunca se pronuncian instantáneamente en la pulsación de teclas — uTalk espera una fracción de segundo (100 milisegundos) antes de hablar, para que la aplicación tenga tiempo de terminar la acción primero.


Como medida de seguridad, cualquier texto anunciado se limita a 200 caracteres; si alguna vez configura una frase personalizada muy larga, se cortará con "...truncado" al final.

2. Manejo inteligente de copia en Modo de exploración


Copiar texto mientras lee una página web en el Modo de exploración de NVDA funciona de manera diferente a copiar en un campo editable normal, y uTalk maneja ambos casos correctamente:


Paso a paso, cuando presiona Control+C:


1. uTalk comprueba si su enfoque actual está dentro de un documento virtual del Modo de exploración (por ejemplo, una página web).


2. Si está en Modo de exploración: una selección de texto realizada con las teclas Mayús+Flechas existe solo dentro del búfer virtual de NVDA. uTalk lee el texto seleccionado directamente del búfer virtual de NVDA y lo coloca en el portapapeles utilizando la función de portapapeles de NVDA.


3. Si no está en Modo de exploración (por ejemplo, escribiendo en un cuadro de texto): ya existe una selección real a nivel del sistema operativo, por lo que uTalk reenvía su Ctrl+C a la aplicación.


4. En ambos casos, una vez realizada la copia, uTalk anuncia "copiar" (o su palabra personalizada).

3. Anuncios exclusivos del Explorador para Copiar ruta y Copiar archivo


El Explorador de Windows tiene dos atajos adicionales que no existen en la mayoría de los otros programas: Copiar como ruta (Ctrl+Mayús+C) y Copiar archivo (Ctrl+Alt+C). uTalk verifica si la ventana activa pertenece al Explorador de Windows antes de anunciar estos comandos.

4. Un atajo, dos funciones: Cambio de idioma y acceso a configuración


NVDA+Alt+T es un atajo único que se comporta de manera diferente según la cantidad de veces que lo pulse:


Una pulsación — uTalk espera hasta 500 milisegundos para ver si vuelve a pulsar. Si no lo hace, cambia su idioma de anuncio activo (inglés o su idioma alternativo) y anuncia inmediatamente el nombre del nuevo idioma.


Doble pulsación (o más) — Si llega una segunda pulsación dentro de los 600 milisegundos, uTalk abre el cuadro de diálogo de Configuración de NVDA directamente en la categoría uTalk.


Internamente, cada pulsación reinicia un temporizador corto para distinguir una sola pulsación de una doble pulsación.

5. Frases de comandos totalmente personalizables


Abrir el panel de configuración de uTalk le proporciona un campo de texto para un nombre de idioma alternativo, además de un campo de texto para cada comando. Lo que escriba en estos campos se convierte en lo que NVDA pronuncia para ese comando.


Un botón "Restaurar valores predeterminados" borra todos los campos a su estado original.


Guardar sus cambios actualiza el complemento en ejecución de inmediato (sin necesidad de reiniciar) y emite una confirmación rápida.


Para evitar que el cuadro de diálogo de configuración se congele al abrirse, lee sus valores actuales de la configuración en memoria del complemento.

6. Almacenamiento confiable de configuración


Sus frases personalizadas se guardan en un archivo de configuración dentro de su carpeta de configuración de usuario de NVDA, en una subcarpeta llamada "ChaiChaimee" de forma segura mediante un archivo temporal.


Si tiene una versión anterior de uTalk, uTalk mueve automáticamente sus configuraciones existentes la primera vez que se carga.
