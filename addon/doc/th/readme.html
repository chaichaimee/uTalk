uTalk


ฟังเสียงยืนยันทุกคำสั่ง คัดลอก, วาง, ตัด, เลิกทำ และบันทึก ทันทีที่เกิดขึ้น — ในคำที่คุณเลือก


ผู้พัฒนา: chai chaimee

เว็บไซต์: https://github.com/chaichaimee/uTalk


บทนำ


uTalk จะพูดเสียงยืนยันสั้น ๆ ทุกครั้งที่คุณใช้แป้นพิมพ์ลัดสำหรับการแก้ไขข้อความทั่วไป — คัดลอก, วาง, ตัด, เลิกทำ, ทำซ้ำ, เลือกทั้งหมด, บันทึก, คัดลอกเส้นทาง และคัดลอกไฟล์ แทนที่จะต้องสงสัยว่า Ctrl+C ของคุณทำงานจริงหรือไม่ uTalk จะประกาศคำว่า "คัดลอก" (หรือคำอื่นที่คุณต้องการ) เบา ๆ ทันทีหลังจากการทำงานเสร็จสิ้น


คำประกาศทุกคำสามารถแทนที่ด้วยข้อความของคุณเองได้ และคุณยังสามารถเก็บบันทึกชุดคำประกาศไว้ได้ถึง 2 ชุด — ตัวอย่างเช่น ภาษาอังกฤษและภาษา native ของคุณ — และสลับระหว่างชุดคำประกาศเหล่านั้นได้ทันทีด้วยการกดแป้นพิมพ์ลัดเพียงครั้งเดียว


uTalk ยังให้ความสำคัญเป็นพิเศษกับการคัดลอกข้อความที่เลือกขณะท่องเว็บในโหมดการเรียกดู (Browse Mode) ของ NVDA ซึ่งปกติแล้ว Ctrl+C จะล้มเหลวโดยไม่มีเสียงแจ้งเตือน เนื่องจากข้อความที่เลือกมีอยู่เฉพาะในบัฟเฟอร์เสมือนของ NVDA เท่านั้น


แป้นพิมพ์ลัด


NVDA+Alt+T
กดครั้งเดียว : สลับระหว่างภาษาอังกฤษและภาษาสำรองของคุณสำหรับการประกาศทั้งหมด
กดสองครั้ง : เปิดแผงตั้งค่า uTalk

Control+C
กดครั้งเดียว : คัดลอก จากนั้นประกาศคำว่า "คัดลอก" (หรือคำที่คุณกำหนดเอง)

Control+V
กดครั้งเดียว : วาง จากนั้นประกาศคำว่า "วาง"

Control+X
กดครั้งเดียว : ตัด จากนั้นประกาศคำว่า "ตัด"

Control+Z
กดครั้งเดียว : เลิกทำ จากนั้นประกาศคำว่า "เลิกทำ"

Control+Y หรือ Control+Shift+Z
กดครั้งเดียว : ทำซ้ำ จากนั้นประกาศคำว่า "ทำซ้ำ"

Control+A
กดครั้งเดียว : เลือกทั้งหมด จากนั้นประกาศคำว่า "เลือกทั้งหมด"

Control+S
กดครั้งเดียว : บันทึก จากนั้นประกาศคำว่า "บันทึก"

Control+Shift+C
กดครั้งเดียว : ประกาศคำว่า "คัดลอกเป็นเส้นทาง" (เฉพาะ Windows Explorer เท่านั้น) จากนั้นจึง执行คำสั่งลัด

Control+Alt+C
กดครั้งเดียว : ประกาศคำว่า "คัดลอกไฟล์" (เฉพาะ Windows Explorer เท่านั้น) จากนั้นจึง执行คำสั่งลัด

uTalk จะดักฟังแป้นพิมพ์ลัดมาตรฐานของ Windows เหล่านี้โดยตรง แป้นพิมพ์ลัดของคุณจะยังคงทำงานได้ตามปกติ — uTalk เป็นเพียงการเพิ่มเสียงยืนยันเข้าไปด้านบนเท่านั้น

คุณสมบัติ

1. เสียงยืนยันสำหรับคำสั่งประจำวัน


เมื่อใดก็ตามที่คุณกด Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+Z, Ctrl+Y (หรือ Ctrl+Shift+Z), Ctrl+A หรือ Ctrl+S ทาง uTalk จะปล่อยให้แป้นพิมพ์ลัดส่งไปยังแอปพลิเคชันก่อน จากนั้นเพียงเสี้ยววินาทีต่อมา จะพูดคำสั้น ๆ เพื่อยืนยันสิ่งที่เกิดขึ้น โดยค่าเริ่มต้นคำเหล่านี้จะเป็นภาษาอังกฤษธรรมดา: "copy", "paste", "cut", "undo", "redo", "select all" และ "save"


เพื่อให้ NVDA ตอบสนองได้อย่างรวดเร็ว เสียงประกาศจะไม่ถูกพูดทันทีในจังหวะที่กดแป้น — uTalk จะรอเสี้ยววินาที (100 มิลลิวินาที) ก่อนที่จะพูด เพื่อให้แอปพลิเคชันมีเวลาทำงานนั้นให้เสร็จสิ้นเสียก่อน


เพื่อความปลอดภัย ข้อความประกาศใด ๆ จะถูกจำกัดไว้ที่ไม่เกิน 200 ตัวอักษร หากคุณตั้งค่าข้อความยาวมาก ข้อความนั้นจะถูกตัดทอนและต่อท้ายด้วย "...ถูกตัดทอน" เพื่อไม่ให้ส่งผลกระทบต่อระบบสังเคราะห์เสียงพูด

2. การจัดการคัดลอกอัจฉริยะในโหมดการเรียกดู (Browse Mode)


การคัดลอกข้อความขณะอ่านหน้าเว็บในโหมดการเรียกดูของ NVDA จะทำงานแตกต่างจากการคัดลอกในฟิลด์ข้อความทั่วไป และ uTalk สามารถจัดการทั้งสองกรณีได้อย่างถูกต้อง:


ขั้นตอนทีละขั้นตอนเมื่อคุณกด Control+C:


1. uTalk จะตรวจสอบว่าโฟกัสปัจจุบันของคุณอยู่ในเอกสารเสมือนของโหมดการเรียกดูหรือไม่ (เช่น หน้าเว็บในเบราว์เซอร์)


2. หากคุณอยู่ในโหมดการเรียกดู: การเลือกข้อความด้วยปุ่ม Shift+ลูกศร จะมีอยู่เฉพาะในบัฟเฟอร์เสมือนของ NVDA เท่านั้น ไม่ใช่การเลือกจริง ๆ ในตัวเบราว์เซอร์ การส่ง Ctrl+C ปกติในสถานการณ์นี้จะไม่คัดลอกอะไรเลย ดังนั้น uTalk จะอ่านข้อความที่เลือกจากบัฟเฟอร์เสมือนของ NVDA โดยตรงและนำไปวางไว้บนคลิปบอร์ดด้วยฟังก์ชันคลิปบอร์ดของ NVDA เอง หากไม่มีการเลือกข้อความ ระบบจะส่งต่อ Ctrl+C ของคุณไปตามปกติ


3. หากคุณไม่ได้อยู่ในโหมดการเรียกดู (เช่น พิมพ์ในกล่องข้อความหรือโปรแกรมประมวลผลคำ): จะมีการเลือกข้อความในระดับ OS จริง ๆ อยู่แล้ว uTalk จึงส่งต่อ Ctrl+C ของคุณไปยังแอปพลิเคชันโดยตรง เพื่อให้แอปพลิเคชันดำเนินการคัดลอกเอง (ซึ่งช่วยรักษาการจัดรูปแบบพิเศษใด ๆ ที่แอปพลิเคชันนั้น ๆ จัดเตรียมไว้)


4. ในทั้งสองกรณี เมื่อการคัดลอกเสร็จสิ้น uTalk จะประกาศคำว่า "คัดลอก" (หรือคำที่คุณกำหนดเอง)

3. เสียงประกาศเฉพาะใน Explorer สำหรับการคัดลอกเส้นทางและคัดลอกไฟล์


Windows Explorer มีแป้นพิมพ์ลัดเพิ่มเติมสองรายการที่ไม่มีในโปรแกรมส่วนใหญ่ ได้แก่ คัดลอกเป็นเส้นทาง (Ctrl+Shift+C) และคัดลอกไฟล์ (Ctrl+Alt+C) uTalk จะตรวจสอบว่าหน้าต่างที่โฟกัสอยู่เป็นของ Windows Explorer จริงหรือไม่ก่อนที่จะประกาศคำสั่งทั้งสองนี้ คุณจึงจะได้ยินคำว่า "คัดลอกเป็นเส้นทาง" หรือ "คัดลอกไฟล์" เฉพาะเวลาทำงานใน Explorer เท่านั้น จะไม่มีทางได้ยินในแอปพลิเคชันอื่นที่มีการใช้คีย์คอมบิเนชันเดียวกัน

4. หนึ่งปุ่มลัด สองหน้าที่: สลับภาษาและเข้าถึงการตั้งค่า


NVDA+Alt+T เป็นแป้นพิมพ์ลัดเดี่ยวที่ทำงานแตกต่างกันไปตามจำนวนครั้งที่คุณกดติดต่อกันอย่างรวดเร็ว:


กดครั้งเดียว — uTalk จะรอสูงสุด 500 มิลลิวินาทีเพื่อดูว่าคุณจะกดซ้ำอีกครั้งหรือไม่ หากไม่กด ระบบจะสลับภาษาประกาศที่ใช้งานอยู่ (ภาษาอังกฤษหรือภาษาสำรอง) และพูดชื่อภาษาใหม่นั้นออกมาดัง ๆ เพื่อยืนยันทันที พร้อมทั้งบันทึกการตั้งค่านี้ไว้ใช้ในครั้งต่อไปที่คุณเปิด NVDA


กดสองครั้ง (หรือมากกว่า) — หากมีการกดครั้งที่สองภายใน 600 มิลลิวินาทีของการกดครั้งแรก uTalk จะเปิดกล่องโต้ตอบการตั้งค่า NVDA ไปที่หมวดหมู่ uTalk โดยตรง เพื่อให้คุณสามารถแก้ไขวลีที่กำหนดเองได้


ภายในระบบ การกดแต่ละครั้งจะรีเซ็ตตัวจับเวลาสั้น ๆ และเมื่อตัวจับเวลาหมดลงโดยไม่มีการกดซ้ำ uTalk ถึงจะตัดสินใจว่าเกิดอะไรขึ้น ซึ่งช่วยให้ปุ่มลัดเดียวสามารถแยกระหว่างการกดครั้งเดียวกับการกดสองครั้งได้

5. วลีคำสั่งปรับแต่งได้อย่างเต็มที่


การเปิดแผงตั้งค่า uTalk (ผ่านกล่องโต้ตอบการตั้งค่าของ NVDA หรือโดยการกด NVDA+Alt+T สองครั้ง) จะมีช่องข้อความสำหรับชื่อภาษาสำรอง และช่องข้อความสำหรับแต่ละคำสั่ง ได้แก่: คัดลอก, คัดลอกเส้นทาง, คัดลอกไฟล์, ตัด, วาง, ทำซ้ำ, บันทึก, เลือกทั้งหมด และเลิกทำ สิ่งที่คุณพิมพ์ในช่องเหล่านี้จะกลายเป็นคำที่ NVDA พูดสำหรับคำสั่งนั้น ๆ เมื่อภาษาสำรองของคุณใช้งานอยู่


ปุ่ม "คืนค่าเริ่มต้น" จะล้างข้อมูลทุกช่องให้กลับมาว่างเปล่า ตรงกับค่าเริ่มต้นที่ตัวเสริมมีมาให้


การบันทึกการเปลี่ยนแปลงของคุณจะอัปเดตตัวเสริมที่กำลังทำงานอยู่ทันที (ไม่ต้องรีสตาร์ท) พร้อมทั้งพูดเสียงยืนยันสั้น ๆ ในภาษาที่ใช้งานอยู่ปัจจุบัน


เพื่อป้องกันไม่ให้กล่องโต้ตอบการตั้งค่าเกิดอาการค้างขณะเปิด แผงตั้งค่าจะอ่านค่าปัจจุบันจากการตั้งค่าในหน่วยความจำของตัวเสริม แทนที่จะอ่านไฟล์กำหนดค่าจากดิ스크โดยตรงในขณะนั้น

6. การจัดเก็บการตั้งค่าที่เชื่อถือได้


วลีที่คุณกำหนดเองจะถูกบันทึกลงในไฟล์กำหนดค่าภายในโฟลเดอร์การกำหนดค่าผู้ใช้ NVDA ในโฟลเดอร์ย่อยชื่อ "ChaiChaimee" การบันทึกทำอย่างปลอดภัยโดย uTalk จะเขียนการตั้งค่าลงในไฟล์ชั่วคราวก่อน จากนั้นจึงสลับแทนที่ไฟล์เดิม และอ่านไฟล์ที่บันทึกซ้ำเพื่อยืนยันว่าตรงกันทุกประการ — ซึ่งช่วยปกป้องการตั้งค่าของคุณไม่ให้สูญหายหรือเสียหายหากมีสิ่งใดมารบกวนระหว่างการบันทึก


หากคุณเคยใช้ uTalk เวอร์ชันเก่าที่เก็บการตั้งค่าไว้ในตำแหน่งอื่น uTalk จะย้ายการตั้งค่าเดิมของคุณโดยอัตโนมัติในครั้งแรกที่โหลด เพื่อให้คุณไม่สูญเสียการตั้งค่าที่เคยปรับแต่งไว้เมื่อทำการอัปเดต



สนับสนุนฉัน
