uTalk


ฟังเสียงยืนยันทุกครั้งที่คัดลอก วาง เลิกทำ และบันทึก ในภาษาของคุณ เฉพาะเมื่อเกิดขึ้นจริงเท่านั้น


ผู้พัฒนา: chai chaimee

URL: https://github.com/chaichaimee/uTalk


บทนำ


uTalk แจ้งยืนยันด้วยเสียงทันทีสำหรับคำสั่งแก้ไขที่คุณใช้ทุกวัน ได้แก่ คัดลอก ตัด วาง เลิกทำ ทำซ้ำ เลือกทั้งหมด บันทึก คัดลอกเป็นที่อยู่ และคัดลอกไฟล์ แทนที่จะต้องคอยสงสัยว่าคีย์ลัดทำงานหรือไม่ คุณจะได้ยินเสียงยืนยันทันที


uTalk จะตรวจสอบว่าการกระทำนั้นส่งผลจริงก่อนจึงค่อยอ่านออกเสียง คุณจึงไม่ได้ยินคำว่า “คัดลอก” เมื่อไม่มีอะไรถูกคัดลอก ส่วนเสริมนี้รองรับโปรไฟล์สองภาษาที่สลับได้ด้วยการกดปุ่มเพียงครั้งเดียว ตั้งค่าพฤติกรรมแยกตามแต่ละแอปพลิเคชันได้ และเลือกได้ว่าจะให้แจ้งเตือนเป็นเสียงพูด อักษรเบรลล์ หรือเสียงบี๊บสั้น ๆ ทุกข้อความสามารถปรับเปลี่ยนเป็นถ้อยคำของคุณเองได้


ปุ่มลัด

NVDA+Alt+T
กด 1 ครั้ง : สลับระหว่างภาษาหลักและภาษาทางเลือก
กด 2 ครั้ง : เปิดการตั้งค่า uTalk
กด 3 ครั้ง : เปิดหรือปิด uTalk สำหรับแอปพลิเคชันปัจจุบัน
กด 4 ครั้ง : ปิดเสียงหรือเปิดเสียงประกาศของ uTalk
คำสั่งปิดเสียงและคำสั่งสำหรับแอปพลิเคชันปัจจุบันสามารถกำหนดปุ่มลัดของตัวเองได้เช่นกัน เปิดเมนู NVDA > การตั้งค่า > ท่าทางการป้อนข้อมูล ค้นหาหมวด uTalk แล้วกำหนดปุ่มให้กับ “Mute or unmute uTalk announcements” หรือ “Turn uTalk off or on for the current application” ส่วนคำสั่งกดหลายครั้งจะปรากฏในชื่อ “uTalk multi tap”

ปุ่มที่ uTalk แจ้งเตือน

Control+C : คัดลอก
Control+X : ตัด
Control+V : วาง
Control+Z : เลิกทำ
Control+Y หรือ Control+Shift+Z : ทำซ้ำ
Control+A : เลือกทั้งหมด
Control+S : บันทึก
Control+Shift+C : คัดลอกเป็นที่อยู่ (แจ้งเตือนเฉพาะใน File Explorer)
Control+Alt+C : คัดลอกไฟล์ (แจ้งเตือนเฉพาะใน File Explorer)

uTalk ส่งปุ่มแต่ละปุ่มต่อไปยังแอปพลิเคชันตามปกติ เพียงแค่เพิ่มการแจ้งเตือนเท่านั้น


ฟีเจอร์


การยืนยันการคัดลอกและตัดอย่างชาญฉลาด

หลังจากคุณกด Control+C หรือ Control+X uTalk จะรอตรวจดูว่าคลิปบอร์ดเปลี่ยนแปลงจริงหรือไม่ หากเปลี่ยน คุณจะได้ยินคำว่า “คัดลอก” หรือ “ตัด” แต่หากไม่มีสิ่งใดถูกนำลงในคลิปบอร์ด คุณจะได้ยินคำว่า “ไม่มีสิ่งที่จะคัดลอก” หรือ “ไม่มีสิ่งที่จะตัด” แทน


ตัวอย่าง: คุณกด Control+C โดยไม่ได้เลือกอะไรไว้ uTalk จะพูดว่า “ไม่มีสิ่งที่จะคัดลอก” แทนที่จะยืนยันการคัดลอกที่ไม่ได้เกิดขึ้นจริง


การวางจะแจ้งเตือนเฉพาะจุดที่สามารถวางได้ ในโหมดอ่านหน้าจอและในช่องแบบอ่านอย่างเดียว Control+V จะไม่ถูกแจ้งเตือน


คุณสามารถปิดการตรวจสอบนี้ได้ด้วยตัวเลือก “Announce copy, cut and paste only when they take effect” ในการตั้งค่า เมื่อปิดตัวเลือกนี้ ชื่อคำสั่งจะถูกแจ้งเตือนเสมอ


การคัดลอกในโหมดอ่านหน้าจอ

บนหน้าเว็บและเอกสารอื่น ๆ ในโหมดอ่านหน้าจอ การเลือกมีอยู่เฉพาะภายใน NVDA ทำให้แอปพลิเคชันเองจะไม่คัดลอกอะไรเลย uTalk จะคัดลอกข้อความที่คุณเลือกให้ ทำให้ Control+C ใช้งานได้ในโหมดอ่านหน้าจอและได้รับการยืนยันเหมือนการคัดลอกทั่วไป


หนึ่งการแจ้งเตือนต่อหนึ่งการกระทำ

หากคุณกดปุ่มลัดค้างไว้หรือกดซ้ำอย่างรวดเร็ว uTalk จะแจ้งเตือนเพียงครั้งเดียว แทนที่จะต่อคิวข้อความซ้ำ ๆ ยาวเหยียด


โปรไฟล์สองภาษา

uTalk เก็บชุดข้อความไว้สองชุด คือ ภาษาหลัก (ภาษาอังกฤษ) และภาษาทางเลือกที่คุณเลือก กด NVDA+Alt+T หนึ่งครั้งเพื่อสลับไปมาระหว่างสองภาษานี้ uTalk จะอ่านชื่อภาษาที่คุณเพิ่งสลับไป และ NVDA จะจำภาษาที่คุณใช้ล่าสุด


หากคำสั่งใดไม่มีข้อความทางเลือก uTalk จะใช้ข้อความภาษาอังกฤษของคำสั่งนั้น หากคุณกดปุ่มสลับก่อนตั้งค่าข้อความทางเลือกใด ๆ uTalk จะแจ้งว่ายังไม่ได้ตั้งค่าภาษาทางเลือก และเตือนให้คุณเปิดการตั้งค่า


วิธีตั้งค่าภาษาทางเลือก:

1. กด NVDA+Alt+T สองครั้งเพื่อเปิดการตั้งค่า uTalk
2. ในช่อง “Alternate language code” ให้พิมพ์ชื่อที่คุณต้องการได้ยินเมื่อสลับมาใช้ภาษานี้
3. ในช่อง “Command translations” ให้พิมพ์ข้อความของคุณเองสำหรับแต่ละคำสั่ง ได้แก่ คัดลอก คัดลอกที่อยู่ คัดลอกไฟล์ ตัด วาง ทำซ้ำ บันทึก เลือกทั้งหมด และเลิกทำ
4. กดตกลง (OK) เพื่อบันทึก
5. กด NVDA+Alt+T หนึ่งครั้งเพื่อเริ่มใช้งานภาษาทางเลือก

ตัวเลือกการส่งออก

เลือกรูปแบบที่ uTalk ใช้แจ้งยืนยันในรายการ “Announcement output”:


- เสียงพูดและอักษรเบรลล์
- เสียงพูดเท่านั้น
- อักษรเบรลล์เท่านั้น
- เสียงบี๊บเท่านั้น


เมื่อเลือก “เสียงบี๊บเท่านั้น” แต่ละคำสั่งจะมีระดับเสียงของตัวเอง คุณจึงแยกแยะ คัดลอก ออกจาก วาง หรือ บันทึก ได้จากระดับเสียงเพียงอย่างเดียว และจะมีเสียงบี๊บแจ้งข้อผิดพลาดที่ทุ้มต่ำกว่าเมื่อไม่มีสิ่งใดให้คัดลอกหรือตัด


ระดับรายละเอียดการแจ้งเตือน

รายการ “Announcement detail” มีสองระดับ คือ สั้น และ ละเอียด


สั้น จะพูดเฉพาะชื่อคำสั่ง เช่น “คัดลอก”


ละเอียด จะเพิ่มข้อมูลเพิ่มเติม:


- คัดลอก ตัด และวาง จะแจ้งจำนวนตัวอักษร และแจ้งจำนวนบรรทัดเมื่อมีมากกว่าหนึ่งบรรทัด เช่น “คัดลอก 2 บรรทัด 50 ตัวอักษร” การขึ้นบรรทัดใหม่ที่ท้ายสุดของข้อความจะไม่ถูกนับเป็นบรรทัดเพิ่มเติม
- ในช่องที่แก้ไขได้ เลิกทำ และ ทำซ้ำ จะบอกว่ามีการเปลี่ยนแปลงอะไร เช่น “เลิกทำ ลบ hello”, “ทำซ้ำ เพิ่ม world” หรือ “เลิกทำ แทนที่ cat ด้วย dog” ข้อความที่ยาวจะถูกย่อให้สั้นลง และข้อความที่มีเฉพาะช่องว่างจะถูกอธิบายว่าเป็น “whitespace”


ข้อมูลแบบละเอียดจะไม่ถูกใช้เมื่อเลือก “เสียงบี๊บเท่านั้น” และสำหรับข้อความขนาดใหญ่มากหรือในแอปพลิเคชันที่อ่านข้อความช้าเกินไป เลิกทำ และ ทำซ้ำ จะแจ้งเฉพาะชื่อคำสั่งล้วน ๆ


กฎรายแอปพลิเคชัน

คุณสามารถกำหนดพฤติกรรมของ uTalk ในแต่ละแอปพลิเคชันได้ แต่ละกฎมีรูปแบบเป็น ชื่อ=ค่า หนึ่งกฎต่อหนึ่งบรรทัด โดยชื่อคือชื่อโปรแกรม (จะใส่ส่วนต่อท้าย “.exe” หรือไม่ก็ได้ และไม่คำนึงถึงตัวพิมพ์เล็กหรือใหญ่) และค่าคือหนึ่งในตัวเลือกต่อไปนี้:


- off : uTalk จะเงียบในแอปพลิเคชันนั้น
- main : ใช้ข้อความภาษาหลักในแอปพลิเคชันนั้นเสมอ
- alt : ใช้ข้อความภาษาทางเลือกในแอปพลิเคชันนั้นเสมอ


ตามค่าเริ่มต้น uTalk จะเงียบใน Command Prompt, PowerShell และ Windows Terminal ส่วนแอปพลิเคชันที่ไม่ได้ตั้งกฎไว้จะใช้ภาษาที่คุณเลือกด้วย NVDA+Alt+T


วิธีเพิ่มกฎ:

1. กด NVDA+Alt+T สองครั้งเพื่อเปิดการตั้งค่า uTalk
2. เลื่อนไปยังช่อง “Application rules”
3. พิมพ์บรรทัดใหม่ เช่น notepad=alt
4. กดตกลง (OK) เพื่อบันทึก

สลับด่วนสำหรับแอปพลิเคชันปัจจุบัน: กด NVDA+Alt+T สามครั้งขณะทำงานอยู่ในแอปพลิเคชัน uTalk จะเพิ่มหรือลบกฎ “off” สำหรับแอปนั้นและแจ้งให้คุณทราบ เช่น “uTalk off for notepad” หรือ “uTalk on for notepad” การเปลี่ยนแปลงจะถูกบันทึกโดยอัตโนมัติ


ปิดเสียง

กด NVDA+Alt+T สี่ครั้งเพื่อปิดเสียงการแจ้งเตือนทั้งหมดของ uTalk และกดสี่ครั้งอีกครั้งเพื่อเปิดเสียง การปิดเสียงจะยกเลิกการแจ้งเตือนที่กำลังรออ่านอยู่ด้วย


ปรับแต่งข้อความได้

ข้อความภาษาหลัก ได้แก่ คัดลอก คัดลอกเป็นที่อยู่ คัดลอกไฟล์ ตัด วาง ทำซ้ำ บันทึก เลือกทั้งหมด และเลิกทำ แต่ละคำสั่งมีช่องทางเลือกในการตั้งค่าที่คุณสามารถเขียนถ้อยคำของตัวเองได้ แต่ละข้อความยาวได้สูงสุด 200 ตัวอักษร


การตั้งค่าที่ปลอดภัย

หน้าต่างการตั้งค่าช่วยป้องกันความผิดพลาดของคุณ:


- ข้อความที่ยาวเกิน 200 ตัวอักษรจะถูกปฏิเสธ และ uTalk จะแจ้งว่าควรย่อช่องใด
- กฎแอปพลิเคชันที่ไม่ถูกต้องจะถูกปฏิเสธ และ uTalk จะแจ้งว่าต้องแก้ไขบรรทัดใด ให้ใช้ รูปแบบ ชื่อ=off, ชื่อ=main หรือ ชื่อ=alt
- ปุ่ม “Restore Defaults” จะคืนค่าทุกการตั้งค่ากลับเป็นค่าเริ่มต้น


การตั้งค่าของคุณจะถูกเก็บไว้ในไฟล์ uTalk.json ที่โฟลเดอร์ userConfig\ChaiChaimee\uTalk\ หากคุณเคยใช้ uTalk รุ่นก่อนหน้า ไฟล์การตั้งค่าเดิมจะถูกย้ายมายังตำแหน่งนี้โดยอัตโนมัติเมื่อเปิด NVDA และไฟล์สำเนาเก่าจะถูกลบออกเมื่อตรวจสอบไฟล์ใหม่เรียบร้อยแล้ว หากค่าใดในไฟล์มีชนิดข้อมูลไม่ถูกต้อง uTalk จะแทนที่ด้วยค่าเริ่มต้น
