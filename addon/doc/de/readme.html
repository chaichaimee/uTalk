uTalk


Hören Sie jede Kopier-, Einfüge-, Ausschneide-, Rückgängig- und Speicheraktion in Echtzeit — in den von Ihnen gewählten Begriffen.


Autor: chai chaimee

URL: https://github.com/chaichaimee/uTalk


Einleitung


uTalk gibt jedes Mal eine kurze akustische Bestätigung aus, wenn Sie eine gängige Bearbeitungskombination verwenden — Kopieren, Einfügen, Ausschneiden, Rückgängig, Wiederherstellen, Alles auswählen, Speichern, Pfad kopieren und Datei kopieren. Anstatt sich zu fragen, ob Ihr Strg+C tatsächlich funktioniert hat, kündigt uTalk leise "kopieren" (oder ein beliebiges bevorzugtes Wort) direkt nach der Aktion an.


Jedes angesagte Wort kann durch Ihren eigenen Text ersetzt werden, und Sie können sogar zwei vollständige Sätze an Ansagen beibehalten — zum Beispiel Englisch und Ihre Muttersprache — und sofort mit einem einzigen Tastendruck zwischen ihnen umschalten.


uTalk schenkt außerdem dem Kopieren von ausgewähltem Text beim Surfen im Internet im NVDA-Modus "Lesemodus" besondere Aufmerksamkeit, bei dem ein normales Strg+C oft stumm fehlschlägt, da die Auswahl nur im virtuellen Puffer von NVDA existiert.


Tastenkombinationen


NVDA+Alt+T
Einfach drücken : Zwischen Englisch und Ihrer Alternativsprache für alle Ansagen umschalten
Doppelt drücken : Das uTalk-Einstellungsfenster öffnen

Strg+C
Einfach drücken : Kopieren, dann "kopieren" (oder Ihr benutzerdefiniertes Wort) ansagen

Strg+V
Einfach drücken : Einfügen, dann "einfügen" ansagen

Strg+X
Einfach drücken : Ausschneiden, dann "ausschneiden" ansagen

Strg+Z
Einfach drücken : Rückgängig, dann "rückgängig" ansagen

Strg+Y oder Strg+Umschalt+Z
Einfach drücken : Wiederherstellen, dann "wiederherstellen" ansagen

Strg+A
Einfach drücken : Alles auswählen, dann "alles auswählen" ansagen

Strg+S
Einfach drücken : Speichern, dann "speichern" ansagen

Strg+Umschalt+C
Einfach drücken : "Als Pfad kopieren" ansagen (nur Windows Explorer), dann den Shortcut ausführen

Strg+Alt+C
Einfach drücken : "Datei kopieren" ansagen (nur Windows Explorer), dann den Shortcut ausführen

uTalk lauscht direkt auf diese Windows-Standardkombinationen. Ihr Shortcut funktioniert weiterhin wie gewohnt — uTalk fügt lediglich eine gesprochene Bestätigung hinzu.

Funktionen

1. Gesprochene Bestätigung für alltägliche Befehle


Wenn Sie Strg+C, Strg+V, Strg+X, Strg+Z, Strg+Y (oder Strg+Umschalt+Z), Strg+A oder Strg+S drücken, leitet uTalk den Tastendruck zuerst an die Anwendung weiter und spricht kurz darauf ein kurzes Wort, das bestätigt, was passiert ist. Standardmäßig sind die Wörter einfaches Englisch: "copy", "paste", "cut", "undo", "redo", "select all" und "save".


Damit NVDA reaktionsfähig bleibt, werden Ansagen niemals sofort beim Tastendruck gesprochen — uTalk wartet einen Bruchteil einer Sekunde (100 Millisekunden) ab, damit die Anwendung die Aktion zuerst tatsächlich abschließen kann.


Aus Sicherheitsgründen ist jeder angesagte Text auf 200 Zeichen begrenzt; falls Sie jemals einen sehr langen benutzerdefinierten Ausdruck konfigurieren, wird dieser am Ende mit "...abgekürtzt" abgeschnitten, damit er die Sprachausgabe niemals überfordert.

2. Intelligente Kopierverarbeitung im Lesemodus


Das Kopieren von Text beim Lesen einer Webseite im NVDA-Lesemodus unterscheidet sich vom Kopieren in einem normalen bearbeitbaren Feld, und uTalk behandelt beide Fälle korrekt:


Schritt für Schritt, wenn Sie Strg+C drücken:


1. uTalk prüft, ob sich Ihr aktueller Fokus innerhalb eines virtuellen Dokuments im Lesemodus befindet (zum Beispiel eine Webseite in einem Browser).


2. Wenn Sie sich im Lesemodus befinden: Eine mit Umschalt+Pfeiltasten vorgenommene Textauswahl existiert nur im virtuellen Puffer von NVDA, nicht als echte Auswahl im Browser selbst. Das Senden des normalen Strg+C würde in dieser Situation überhaupt nichts kopieren. Stattdessen liest uTalk den ausgewählten Text direkt aus dem virtuellen Puffer von NVDA und legt ihn mithilfe der eigenen Zwischenablagefunktion von NVDA in der Zwischenablage ab. Wenn kein Text ausgewählt ist, leitet es Ihr Strg+C einfach normal weiter.


3. Wenn Sie sich nicht im Lesemodus befinden (z. B. beim Tippen in ein Textfeld oder eine Textverarbeitung): Es existiert bereits eine echte Auswahl auf Betriebssystemebene, sodass uTalk Ihr Strg+C zuerst an die Anwendung weiterleitet, damit diese ihr eigenes Kopieren durchführt (wodurch eventuelle Spezialformatierungen erhalten bleiben).


4. In beiden Fällen kündigt uTalk nach Abschluss des Kopiervorgangs "kopieren" (oder Ihr benutzerdefiniertes Wort) an.

3. Nur-Explorer-Ansagen für Pfad kopieren und Datei kopieren


Der Windows Explorer verfügt über zwei zusätzliche Tastenkombinationen, die in den meisten anderen Programmen nicht existieren: Als Pfad kopieren (Strg+Umschalt+C) und Datei kopieren (Strg+Alt+C). uTalk prüft, ob das aktuell fokussierte Fenster tatsächlich zum Windows Explorer gehört, bevor diese beiden Befehle angesagt werden, sodass Sie "als Pfad kopieren" oder "datei kopieren" nur hören, wenn Sie im Explorer selbst arbeiten.

4. Ein Hotkey, zwei Aufgaben: Sprachumschaltung und Zugriff auf Einstellungen


NVDA+Alt+T ist ein einzelner Hotkey, der sich je nach Anzahl der aufeinanderfolgenden Taps unterschiedlich verhält:


Einfach drücken — uTalk wartet bis zu 500 Millisekunden, um zu sehen, ob Sie erneut tippen. Wenn nicht, schaltet es Ihre aktive Ansagesprache (Englisch oder Ihre Alternativsprache) um und spricht sofort den Namen der neuen Sprache als Bestätigung aus und speichert diese Auswahl.


Doppelt drücken (oder öfter) — Wenn ein zweiter Tap innerhalb von 600 Millisekunden erfolgt, öffnet uTalk stattdessen das NVDA-Einstellungsdialogfeld direkt in der uTalk-Kategorie.


Intern setzt jeder Tap einen kurzen Timer zurück; erst wenn der Timer abläuft, entscheidet uTalk, was tatsächlich passiert ist.

5. Vollständig anpassbare Befehlsausdrücke


Das Öffnen des uTalk-Einstellungsfelds bietet Ihnen ein Textfeld für einen Alternativsprachennamen sowie jeweils ein Textfeld für jeden Befehl: Kopieren, Pfad kopieren, Datei kopieren, Ausschneiden, Einfügen, Wiederherstellen, Speichern, Alles auswählen und Rückgängig. Was auch immer Sie eingeben, wird von NVDA für diesen Befehl gesprochen.


Eine Schaltfläche "Standardwerte wiederherstellen" setzt jedes Feld auf leer zurück und entspricht den integrierten Standards von uTalk.


Das Speichern Ihrer Änderungen aktualisiert das laufende Add-On sofort (kein Neustart erforderlich) und gibt eine kurze Bestätigung aus.


Um zu verhindern, dass das Einstellungsdialogfeld beim Öffnen einfriert, liest das Bedienfeld seine aktuellen Werte aus den speicherinternen Einstellungen des Add-Ons.

6. Zuverlässige Speicherung der Einstellungen


Ihre angepassten Phrasen werden in einer Konfigurationsdatei in Ihrem NVDA-Benutzerkonfigurationsordner in einem Unterordner namens "ChaiChaimee" gespeichert. Das Speichern erfolgt sicher über eine temporäre Datei und automatisches Neuladen.


Wenn Sie eine ältere Version von uTalk verwenden, verschiebt uTalk Ihre vorhandenen Einstellungen beim ersten Laden automatisch, sodass Sie Ihre Anpassungen beim Aktualisieren nicht verlieren.
